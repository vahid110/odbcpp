# Optional delegation

[DEVELOPMENT_WORKFLOW.md](DEVELOPMENT_WORKFLOW.md) is the sole canonical workflow.
One Windows coordinator owns a bounded task end-to-end and may delegate worthwhile,
independent implementation under exact file/contract leases. One substantive
independent diff/result review covers the completed candidate. No permanent lanes,
supervisor loops, automatic work dispatch or timer-based continuation are required.

The [previous parallel policy](docs/history/workflow-2026-10-19/PARALLEL_WORKFLOW.md.snapshot)
is retained only as historical evidence. It grants no current authority.
Product development and migration integration remain PAUSED until human resume.
